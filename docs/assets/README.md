# docs/assets/

Two generated architecture diagrams live in this repo, each with one job. `src/inclusify_agent/static/architecture.png` is the diagram served by `GET /api/model_architecture`: minimal, spec-§C-matched (module names pulled from `MODULE_BY_TASK` so they can never drift from `steps[].module`), regenerated via `python scripts/gen_architecture.py`. `docs/assets/inclusify-architecture-deck.png` is the richer presentation version for slides — it spells out the full `EvidenceInvestigator` tool loop (plan → search → review → sufficiency check → finalize, with the revise/live-search branches), the provider panels, and a legend — regenerated via `python scripts/gen_deck_diagram.py`. Both are deterministic Pillow renders (fixed pixel layout, no timestamps or randomness; each script self-checks that two runs produce a byte-identical PNG) and both are committed rather than built at deploy time. They supersede the earlier hand-made GPT-drafted diagrams.
